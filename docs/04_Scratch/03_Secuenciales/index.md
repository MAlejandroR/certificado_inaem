# Estructuras secuenciales

Cuando programamos, lo más habitual es que las instrucciones se ejecuten **una detrás de otra, siguiendo un orden determinado**.

Esta forma de organizar las instrucciones se denomina **estructura secuencial** y es la más sencilla de la programación.

El ordenador ejecuta la primera instrucción, después la segunda, luego la tercera... hasta completar todas las acciones.

Por ejemplo, imaginemos que queremos que un personaje de Scratch:

1. 🚶 Avance 50 pasos.
2. ⏰ Espere 2 segundos.
3. 🔄 Gire 90 grados.
4. 💬 Diga «¡He terminado!».

El orden es importante: si cambiamos el orden de las instrucciones, el resultado del programa puede ser diferente.

En Scratch encontramos instrucciones secuenciales principalmente en las siguientes categorías:

- 🔵 **Movimiento:** desplazar, girar o cambiar la posición de un personaje.
- 🟣 **Apariencia:** mostrar mensajes, cambiar disfraces o modificar el tamaño.
- 🩷 **Sonido:** reproducir sonidos o modificar el volumen.

Estas instrucciones se representan mediante **bloques que podemos encajar unos debajo de otros**, indicando así el orden en el que deben ejecutarse.

::: tip 💡 Idea fundamental
Una estructura secuencial consiste en **ejecutar instrucciones una detrás de otra, en el orden en el que aparecen**.

Es la base de cualquier programa y, combinándola con las estructuras selectivas y repetitivas, podremos construir programas mucho más complejos.

En PHP también escribiremos instrucciones secuenciales, pero en lugar de utilizar bloques gráficos, las escribiremos mediante código.
:::
