# Instalación
Scratch no hace falta instalarlo, ya que se puede usar directamente desde el navegador. Para ello, hay que acceder a la página web de Scratch y crear una cuenta de usuario. Una vez creada la cuenta, se puede empezar a programar directamente desde el navegador.

# Entorno de ejecución
Es complicado al principio localizar los elementos del entorno de ejecución, pero con un poco de práctica se puede llegar a dominarlo.

Veremos cómo las insstrucciones se agrupan en bloques y cómo se pueden arrastrar y soltar para formar un programa. Además, aprenderemos a utilizar los diferentes tipos de bloques y cómo interactúan entre sí.
