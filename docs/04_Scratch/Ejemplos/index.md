## Consideraciones Finales

Para realizar el ejercicio necesitarás utilizar los conceptos de programación que hemos estudiado:

- **Eventos:** para iniciar el juego y controlar el movimiento.
- **Estructuras selectivas:** para detectar colisiones y comprobar las condiciones de victoria o derrota.
- **Estructuras repetitivas:** para mantener el movimiento y comprobar continuamente las colisiones.
- **Variables:** para controlar las vidas, las manzanas recogidas y, opcionalmente, el tiempo.
- **Mensajes:** para coordinar el comportamiento de los diferentes objetos del juego.
- **Bloques:** para coordinar el comportamiento de los diferentes objetos del juego.
- **Creación de clones:** para coordinar el comportamiento de los diferentes objetos del juego.
